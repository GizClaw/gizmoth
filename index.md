# GizMoth

A desktop workspace for managing GizOS devices and building Lua apps with an AI coding assistant.

- Pair and manage supported devices.
- Create, edit and package Lua apps.
- Use an AI assistant and offline GizOS documentation.
- Send app requests to devices or independent simulators.

Device interoperability and end-to-end simulator execution are still being verified.
