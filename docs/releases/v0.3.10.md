# GizMoth v0.3.10

The Agents page now supports Pi alongside Claude Code, Codex, Gemini CLI and OpenCode.

- Preview, install, update or uninstall the GizMoth Skill in Pi's user directory, `~/.pi/agent/skills/gizmoth/SKILL.md` by default. `PI_CODING_AGENT_DIR` follows Pi's path rules, including home expansion, file URLs and Windows shell-drive paths. Unusable overrides show an error before installation.
- Use the same Skill through Pi's interactive, print and RPC modes. It provides GizMoth CLI queries for service status, serial discovery and logs, plus the existing WebSocket workflow for authorized device commands.
- Pi also discovers the Codex installation in `~/.agents/skills`. One copy is enough; if both targets are installed, Pi prefers its agent-directory copy and reports a name collision. Reload Skills with `/reload` or restart Pi after installation or updates.

Installation preserves global instructions, other Skills and sibling files. See the [agent integration guide](../agents.md) for paths and usage.

Installers are provided for macOS Apple Silicon, macOS Intel and Windows x64. macOS bundles are Developer ID signed and notarized; updater artifacts are signed.
