# GizMoth v0.3.0

## macOS fullscreen titlebar

- Remove the reserved window-control space from the titlebar when the main window enters fullscreen, keeping the sidebar toggle aligned with the left edge.
- Restore the window-control inset when leaving fullscreen. Both expanded and collapsed sidebars follow the native window state, including when the interface reloads while already fullscreen.

This minor release includes the device task-session behavior and agent compatibility changes introduced in [v0.2.1](v0.2.1.md).
