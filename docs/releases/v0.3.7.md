# GizMoth v0.3.7

Development-environment catalogs now live in a persistent local Git repository, with incremental updates and offline browsing.

- Clone `GizClaw/gizmoth-devenv` once into `<app data>/devenv/registry/repository/`. Later refreshes reuse the checkout and run `git pull --ff-only`.
- Load the last validated catalog immediately on startup. Failed updates and offline restarts keep the previously validated catalog available, including caches created by earlier GizMoth versions.
- Validate every catalog against one committed revision before publishing it. Preserve local edits and reject changed origins, branches, local-only commits and diverged history.
- Bound Git command output and runtime, disable interactive prompts and repository hooks, and terminate transport subprocesses when a refresh times out or is cancelled.

Git must be installed and available on the desktop application's PATH. Browser-only catalog browsing continues to use public GitHub metadata.

Signed and notarized macOS installers are provided for Apple Silicon and Intel, alongside the Windows installer and signed automatic-update payloads.
