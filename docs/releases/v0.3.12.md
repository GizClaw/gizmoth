# GizMoth v0.3.12

Compiling → Artifacts now keeps build times aligned and opens details directly beneath each row.

- Click an artifact row, or press Enter/Space, to expand its files, sizes, full-path and artifact-ID copy actions, workspace, command and **Show in Finder** inline, following the download-management list style.
- Use the right-edge **…** menu to **Install**, **Pin**/**Unpin** or **Delete** that artifact. Install opens the existing device dialog and is disabled when no `.update.tar.zlib` firmware package is available. Delete confirms the selected artifact before removing it.
- Shared columns keep times and menus aligned across pinned, unpinned and non-installable artifacts. Long titles truncate, and narrow windows hide file summaries to leave room for titles and controls. Row expansion and menus support keyboard navigation.
- CI and release builds recreate the cached OpenVMM worktree before building it, avoiding stale Git metadata after cache restoration.

See the [compilation guide](../compiling.md) for artifact handling and firmware installation.

Installers are provided for macOS Apple Silicon, macOS Intel and Windows x64. macOS bundles are Developer ID signed and notarized; updater artifacts are signed.
