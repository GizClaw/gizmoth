# GizMoth v0.3.13

On Macs with Apple silicon, builds can now use a worktree directly. Set `spec.workspaceMode` to `"direct"` in a compile request or `CompileTask` to skip copying the source into a VM slot. Existing requests default to `"sync"` for projects that build in a writable source tree.

- Direct builds start in `/src`, the read-only host worktree. Write build products to `/out`, which maps to the worktree's own `out/` directory. For example, `cmake -S . -B /out/debug` keeps build state available for the next run.
- GizMoth gives each direct build a fresh VM and lets one build at a time write to a given worktree. Builds for independent worktrees can use other available slots.
- Artifact globs select files relative to `/out` and preserve their on-disk spelling. GizMoth archives each matched path once, records its size, SHA-256 and collecting job, and uses APFS copy-on-write clones where available. Archived outputs survive later builds and worktree removal.

See the [direct build guide](../compiling.md#direct-workspace-builds) and [example compile request](../execution.md#request-document).

Installers are available for macOS Apple silicon, macOS Intel and Windows x64. macOS apps are Developer ID signed and notarized. Updater packages are signed on all three platforms.
