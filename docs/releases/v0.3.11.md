# GizMoth v0.3.11

Build GizOS firmware in managed Linux VM slots and use one JSON request interface for compilation, serial operations, job status and logs.

- Compile with complete vendor SDKs from their original upstream sources, including pinned Git revisions, required submodules and LFS objects. Slots share Bazel and ccache services and divide the configured total CPU and memory budget evenly. Source and program mounts are read-only; each slot has a writable build directory. Linux VM compilation is available on macOS Apple Silicon.
- Use `gizmoth request -f request.json` or `gizmoth request -f -`. Requests wait by default; `--detach` returns a job receipt while the resident service continues the task. `--output` writes the final JSON to a new file. Discover operations and their schemas with `describe`.
- Query configured serial devices, discovered interfaces and cached device status through `serial.list`, `serial.ports` and `serial.status`. Submit supported device actions, inspect or cancel jobs, and read logs through the same request envelope.
- Create JSON tasks in the execution page and expand compact history rows to inspect configuration, timing, results and output paths. Compile tasks expose their accepted configuration and open build logs in a separate terminal page with ANSI colors.
- Preserve portable Git state and legacy build data during migration. First-run package preparation starts automatically unless paused. Package rows show actual Linux executable and library locations.
- Keep cancellation available when the execution queue is full. Release Skill and service coordination locks explicitly, preventing transient contention during concurrent process startup. Host serial-core builds no longer download an unused BK firmware compiler, and platform-specific execution code is correctly gated on Windows.

The request command replaces the previous `exec` command. See the [request interface](../execution.md), [compilation guide](../compiling.md) and [agent integration guide](../agents.md) for schemas, examples and platform requirements. Existing agent Skill installations can be updated from the Agents page.

Installers are provided for macOS Apple Silicon, macOS Intel and Windows x64. macOS bundles are Developer ID signed and notarized; updater artifacts are signed.
