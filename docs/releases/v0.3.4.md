# GizMoth v0.3.4

## Simulator navigation

- Show the number of saved simulators beside the Simulators entry in the sidebar, matching the existing device and serial-port counts.
- Refresh the count when simulators are created or deleted, including changes from another window. Hide the badge when no simulators exist.
- Ignore stale refresh responses and retain the last known count if a refresh fails.

## Native test reliability

- Avoid WebdriverIO's automatic selection of a simulator window that is being destroyed during native storage checks.
- Keep explicit window-destruction waits and the existing storage, isolation, ownership and deletion assertions.
